# Pinch

Telegram-бот и мини-приложение для учёта доходов и расходов. Пишешь или говоришь боту «кофе 350» или «получил зарплату 80000» — запись попадает в базу, а в мини-приложении видно баланс, лимит на месяц, сравнение категорий и историю.

## Запуск (всё бесплатно)

1. **Бот.** В Telegram открой @BotFather, команда `/newbot`, сохрани токен.
2. **Твой id.** Напиши @userinfobot, он пришлёт числовой id. Он нужен, чтобы бот работал только для тебя.
3. **База.** Зарегистрируйся на neon.tech, создай проект и скопируй connection string (`postgresql://...`).
4. **Сервер.** На render.com выбери New, затем Blueprint (или Web Service), подключи этот репозиторий. Переменные окружения:
   - `BOT_TOKEN` — токен из шага 1
   - `DATABASE_URL` — строка из шага 3
   - `ALLOWED_USER_IDS` — твой id из шага 2
   - `GROQ_API_KEY` — по желанию, для голоса (бесплатный ключ на console.groq.com)
5. После деплоя открой бота и нажми /start. Мини-приложение откроется кнопкой меню.
6. **Чтобы бот не засыпал:** на uptimerobot.com добавь HTTP-монитор на `https://<твой-сервис>.onrender.com/health` с интервалом 5 минут.

## Как пользоваться

- Текст или голос: `такси 500`, `20 долларов подписка`, `вчера кофе 300`, `+5000 подработка`.
- `/currency USD` — основная валюта, `/limit 50000` — лимит на месяц.
- Под каждой записью есть кнопка «Отменить».

## Состав

- `backend/` — FastAPI, бот на aiogram, PostgreSQL (`schema.sql`)
- `webapp/index.html` — мини-приложение
